# THE GREAT ESCAPE — 자캐 역극 탈출 게임

친구들이 각자 자기 캐릭터(자캐)를 데리고 접속해서, 대탈출처럼 갇힌 곳을 함께 탈출하는 온라인 역극 게임입니다.
멤버들은 서로 다른 곳에서 깨어나고, **같은 구역이거나 문·벽 하나 너머에 있어야** 목소리가 닿습니다.

## 배포 (Cloudflare)

Cloudflare Workers 무료 플랜으로 돌아갑니다. 방마다 Durable Object 하나가 게임을 진행하고,
방 정보와 대화 기록을 저장해 두기 때문에 서버가 잠들거나 다시 시작돼도 진행 중인 방이 사라지지 않습니다.

### 방법 1: 대시보드에서 GitHub 저장소 연결 (추천)

1. [Cloudflare](https://dash.cloudflare.com)에 가입하고 로그인합니다.
2. **Workers & Pages → 만들기(Create)**에서 **저장소 가져오기(Import a repository)**를 고르고 GitHub를 연결합니다.
3. 이 저장소를 고릅니다. 배포 명령은 기본값(`npx wrangler deploy`)을 그대로 둡니다.
4. 배포가 끝나면 나오는 주소(`https://the-great-escape.<내 계정>.workers.dev`)를 친구들과 공유합니다.

이후에는 연결한 브랜치에 새 커밋이 올라올 때마다 자동으로 다시 배포됩니다.

### 방법 2: 내 컴퓨터에서 명령어로 배포

Node.js 20 이상이 필요합니다.

```bash
npm install
npx wrangler login   # 브라우저가 열리면 Cloudflare 계정으로 허락
npm run deploy
```

### 내 컴퓨터에서 실행해 보기

```bash
npm install
npm run dev          # http://localhost:8787
```

무료 플랜의 사용량 한도는 Cloudflare 요금 안내에서 확인할 수 있습니다. 친구들끼리 하는 규모라면 넉넉합니다.
아무도 접속하지 않은 방은 6시간 뒤 자동으로 정리됩니다.

## 플레이 방법

1. **캐릭터 관리**: 이름, 테마색, 도트 초상화(8종), 성격, 특기, 한 줄 소개를 입력합니다.
   **그림 올리기**로 내 캐릭터 그림을 넣을 수 있습니다. 흰 배경은 자동으로 지울 수 있고, 같은 그림에서 프사를 잘라 냅니다.
   전신 그림은 지도 위를 걸어 다니고, 프사는 채팅과 목록에 나옵니다.
   캐릭터는 내 브라우저에 저장되고, JSON 파일로 내보내거나 불러올 수 있습니다.
2. **친구와 플레이**
   - 방장: 참가 방식(내 캐릭터 / 진행자)과 에피소드를 고르고 **방 만들기**를 누릅니다. 4글자 초대 코드와 초대 링크가 나옵니다.
   - 친구: 초대 링크를 열거나 초대 코드를 입력하고, 데려갈 캐릭터를 골라 **참가하기**를 누릅니다.
   - 모두 모이면 방장이 **녹화 시작**을 누릅니다. 캐릭터는 최대 6명, 진행자는 1명까지입니다.
   - 대기실에서 **내 캐릭터 바꾸기**로 데려갈 캐릭터를 바꿀 수 있습니다.
   - 녹화가 시작된 뒤에도 같은 초대 코드로 **도중에 합류**할 수 있습니다.
   - 방장은 누구든, 다른 사람은 접속이 끊긴 멤버만 **내보내기** 할 수 있습니다.
3. **탈출**: 화면은 3단입니다.
   - **왼쪽 (출연진)**: 같은 구역에 있는 멤버만 위치와 소지품이 보입니다. 내 아이템을 눌러 같은 구역 멤버에게 건넬 수 있습니다.
   - **가운데 (지도와 구역)**: 내 캐릭터가 가 본 곳만 지도에 드러납니다. 옆 구역을 눌러 이동하고, 아래에서 물건을 조사합니다.
   - **오른쪽 (채팅)**: 내 캐릭터에게 들리는 소리만 나옵니다.
4. **목소리가 닿는 거리**: 소리는 문이나 얇은 벽을 하나 건널 때마다 한 칸씩 멀어집니다.
   - 속삭임: 같은 구역에만 들립니다.
   - 대사: 같은 구역에 들리고, 바로 옆 구역에는 웅얼거리며 일부만 들립니다.
   - 외침: 옆 구역까지 또렷하게, 두 칸 떨어진 구역에는 웅얼거리며 들립니다.
   - 행동: 같은 구역에서만 보입니다.
5. **진행자(GM)**: 캐릭터 없이 모든 구역과 모든 대화를 지켜봅니다. 지도에서 구역을 골라 그 구역에만 나레이션을 넣거나,
   전체에 나레이션을 넣고, 시간을 멈추고, 시간 감소 없이 힌트를 줄 수 있습니다.
6. **성격과 특기**: 성격에 따라 자동 리액션 대사가 나오고, 특기는 퍼즐 풀이에 영향을 줍니다.
   - 관찰력: 조사할 때 추가 단서를 찾습니다.
   - 두뇌: 자물쇠 힌트를 무료로 봅니다.
   - 괴력: 일부 자물쇠를 힘으로 엽니다.
   - 행운: 틀려도 시간이 줄지 않습니다.
7. 오답을 내면 1분이 줄어듭니다. **힌트**는 지금 플레이 중인 멤버 과반수가 찬성하면 나오고, 모두의 시간이 3분 줄어듭니다.
   최종 탈출은 **전원이 한 곳에 모여야** 할 수 있습니다. 접속이 끊긴 멤버는 기다리지 않습니다.
8. **엔딩**: 내 캐릭터 시점의 역극 로그를 `.txt`로 저장할 수 있습니다. 진행자는 전체 로그를 저장합니다.

창을 닫거나 새로고침해도 타이틀 화면의 **이어하기**로 같은 자리로 돌아올 수 있습니다.
다른 기기로 옮길 때는 게임 화면 왼쪽 아래의 **초대 코드와 복귀 번호**를 **친구와 플레이 → 다른 기기에서 이어하기**에 넣으면 됩니다.
캐릭터는 **캐릭터 관리 → 코드로 복사 / 코드 붙여넣기**로 옮길 수 있습니다.
모두가 나가 있어도 시간은 계속 흐르고, 시간이 다 되면 게임이 끝납니다.

## 설정

게임 화면 위쪽의 **효과** 버튼으로 깜빡임·번쩍임 화면 효과를, **소리** 버튼으로 효과음과 배경음을 끄고 켤 수 있습니다.
설정은 기기에 저장됩니다. 효과음과 배경음은 파일 없이 브라우저에서 직접 만들어 냅니다.

휴대폰에서는 화면 아래 **지도 / 채팅 / 출연진** 탭으로 한 화면씩 봅니다. 새 메시지가 오면 채팅 탭에 숫자가 뜹니다.

## 테스트

```bash
npm test
```

게임 핵심 규칙(들리는 범위, 정답 비공개, 퍼즐, 이벤트, 내보내기, 도중 합류, 힌트 투표, 저장)을 테스트 전용 시나리오로 확인하고,
실제 에피소드 데이터가 서로 맞물리는지 검사합니다. 테스트에는 실제 에피소드의 정답이 들어 있지 않습니다.
GitHub에 올릴 때마다 GitHub Actions에서 자동으로 실행됩니다.

## 자동 연출 (진행자 없이도 진행)

시나리오에 적어 둔 **이벤트**가 조건이 맞는 순간 자동으로 나옵니다. 진행자는 있어도 되고 없어도 됩니다.

- **조건**: 게임 시작, 누군가 어떤 구역에 처음 들어감, 어떤 물건을 조사함, 퍼즐을 풂, 아이템을 얻음,
  전원이 한 곳에 모임, 남은 시간이 N분이 됨, 한동안 아무 진전이 없음
- **연출**: 나레이션, 스피커·수화기 같은 목소리(거리에 따라 웅얼거림도 적용), 알림,
  화면 효과(형광등 깜빡임·정전·경보), 문 열기·잠그기, 시간 늘리기·줄이기, 자동 힌트

연출은 그 구역에만, 또는 전체에 내보낼 수 있습니다. 적는 방법은 `src/scenarios.js` 맨 위 주석에 있습니다.

## 에피소드

| 에피소드 | 시간 | 장르 |
| --- | --- | --- |
| 제1화 · 지하 연구소 | 30분 | 미스터리 |
| 제2화 · 폐병원 7병동 | 35분 | 공포 |
| 제3화 · 청운교도소 | 30분 | 탈옥 |
| 제4화 · 한빛중학교 구관 | 30분 | 학교 괴담 |

스포일러 주의: `src/scenarios.js`에는 퍼즐 정답과 이벤트가 그대로 적혀 있습니다. 직접 플레이할 거라면 열어 보지 마세요.

모든 에피소드는 〈대탈출〉 같은 방탈출 예능의 분위기를 참고해 새로 만든 오리지널입니다.

## 공정한 플레이

판정은 모두 서버에서 합니다. 퍼즐 정답과 다른 구역의 대화는 브라우저로 아예 보내지 않으므로,
개발자 도구를 열어도 볼 수 없습니다. 웅얼거리는 소리도 서버에서 글자를 지운 뒤에 보냅니다.

## 에피소드 추가하기

`src/scenarios.js`의 `SCENARIOS` 배열에 같은 형식으로 에피소드를 추가하면 방 만들기 화면에 나타납니다.
이야기를 글로만 써 두고 이 형식으로 옮겨 달라고 Claude에게 맡겨도 됩니다.
지도 크기(`map`), 구역 위치(`rect`), 시작 구역(`starts`), 구역 사이 연결(`links`: 통로, 문, 소리만 통하는 벽)을
에피소드마다 다르게 정할 수 있습니다. 필드 설명은 파일 맨 위 주석에 있습니다.

## 도트 아이콘 추가하기

`public/js/pixels.js`의 `PIXEL_ICONS`에 12줄 × 12글자 격자를 추가하면 됩니다. 글자 하나가 픽셀 하나이고,
`.`은 투명, 나머지 글자는 `PIXEL_PALETTE`의 색입니다. 시나리오의 `icon` 값에 그 이름을 쓰면 됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `src/worker.js` | Cloudflare Worker(주소 연결)와 방마다 하나씩 도는 Durable Object(접속, 저장, 타이머) |
| `src/room.js` | 방, 게임 진행, 소리 전달, 판정 |
| `src/scenarios.js` | 에피소드(지도, 구역, 연결, 퍼즐, 힌트) — 정답이 있어서 브라우저로 보내지 않음 |
| `wrangler.jsonc` | Cloudflare 배포 설정 |
| `public/index.html` | 화면 구조 |
| `public/style.css` | 디자인 (음산한 빈티지 도트 테마) |
| `public/js/game.js` | 캐릭터 관리, 방 만들기·참가, 게임 화면 |
| `public/js/pixels.js` | 12×12 도트 아이콘과 캐릭터 초상화 |
| `public/js/voices.js` | 성격별 리액션 대사와 특기 정의 (서버와 함께 씀) |
| `public/js/sound.js` | 효과음과 배경음 (Web Audio로 생성) |
| `tests/` | 자동 테스트 |
| `public/fonts/` | Galmuri 픽셀 폰트 (SIL OFL 1.1, `public/fonts/OFL.md`) |
