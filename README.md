# THE GREAT ESCAPE — 자캐 역극 탈출 게임

내 캐릭터(자캐)들을 출연시켜 대탈출처럼 갇힌 곳을 탈출하는 웹 게임입니다.
설치나 빌드 없이 `index.html`만 열면 실행됩니다.

## 실행

```bash
python3 -m http.server 8000   # 그다음 http://localhost:8000
```

GitHub Pages에 올리면 그대로 웹에서 플레이할 수 있습니다.

## 플레이 방법

1. **캐릭터 관리**: 이름, 이모지 또는 이미지 URL, 테마색, 성격, 특기, 한 줄 소개를 입력합니다.
   캐릭터는 브라우저에 저장되고, JSON 파일로 내보내거나 불러올 수 있습니다.
2. **출연진 선택**: 에피소드와 멤버를 1~6명 고릅니다. 멤버는 시나리오의 시작 구역에 무작위로 흩어져 깨어납니다.
3. **탈출**: 화면은 3단입니다.
   - **왼쪽 (멤버)**: 행동할 멤버를 고릅니다. 위치와 소지품이 보이고, 아이템을 눌러 같은 구역의 멤버에게 건넬 수 있습니다.
   - **가운데 (지도와 구역)**: 지도에서 옆 구역을 누르거나 출구 버튼으로 이동합니다. 가 본 곳만 지도에 드러나고, 그 옆은 `???`로 보입니다.
     아래 구역 패널에서 물건을 조사하고 퍼즐을 풉니다.
   - **오른쪽 (구역 채팅)**: 구역마다 채팅 채널이 따로 있습니다. 상단 탭으로 멤버가 있는 다른 구역이나 🎬 제작진 시점(전체 로그)을 볼 수 있습니다.
4. **목소리가 닿는 거리**: 소리는 문이나 얇은 벽을 하나 건널 때마다 한 칸씩 멀어집니다.
   - 🤫 속삭임: 같은 구역에만 들립니다.
   - 💬 대사: 같은 구역에 들리고, 바로 옆 구역에는 웅얼거리며 일부만 들립니다.
   - 📢 외침: 옆 구역까지 또렷하게, 두 칸 떨어진 구역에는 웅얼거리며 들립니다.
   - ✋ 행동은 같은 구역에서만 보이고, 📖 나레이션은 보고 있는 채널에 남습니다.
5. **성격과 특기**: 성격(차분함, 겁많음, 활발함, 냉소적, 엉뚱함)에 따라 자동 리액션 대사가 나옵니다. 특기는 퍼즐 풀이에 영향을 줍니다.
   - 관찰력: 조사할 때 추가 단서를 찾습니다.
   - 두뇌: 자물쇠 힌트를 무료로 봅니다.
   - 괴력: 일부 자물쇠를 힘으로 엽니다.
   - 행운: 틀려도 시간이 줄지 않습니다.
6. 오답을 내면 1분, 힌트를 보면 3분이 줄어듭니다. 최종 탈출은 **전원이 한 곳에 모여야** 할 수 있습니다.
7. **엔딩**: 역극 전체를 구역 표시와 함께 `.txt` 로그로 저장할 수 있습니다.

진행 상황은 자동으로 저장되어 타이틀 화면의 **이어하기**로 돌아올 수 있습니다.

## 에피소드 추가하기

`js/scenarios.js`의 `SCENARIOS` 배열에 같은 형식으로 에피소드를 추가하면 선택 화면에 나타납니다.
지도 크기(`map`), 구역 위치(`rect`), 시작 구역(`starts`), 구역 사이 연결(`links`: 통로, 문, 소리만 통하는 벽)을
에피소드마다 다르게 정할 수 있습니다. 필드 설명은 파일 맨 위 주석에 있습니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `js/voices.js` | 성격별 리액션 대사와 특기 정의 |
| `js/scenarios.js` | 에피소드(지도, 구역, 연결, 퍼즐, 힌트) |
| `js/game.js` | 게임 로직 |
