# THE GREAT ESCAPE — 자캐 역극 탈출 게임

친구들이 각자 자기 캐릭터(자캐)를 데리고 접속해서, 대탈출처럼 갇힌 곳을 함께 탈출하는 온라인 역극 게임입니다.
멤버들은 서로 다른 곳에서 깨어나고, **같은 구역이거나 문·벽 하나 너머에 있어야** 목소리가 닿습니다.

## 실행 (내 컴퓨터)

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 컴퓨터 IP>:3000`으로 접속할 수 있습니다.

## 배포 (친구들이 인터넷으로 접속)

[Render](https://render.com) 무료 플랜으로 배포하는 방법입니다.

1. Render에 가입하고 **New → Blueprint**를 누릅니다.
2. 이 GitHub 저장소를 연결합니다. 저장소의 `render.yaml`을 읽어 자동으로 설정됩니다.
3. 배포가 끝나면 나오는 주소(`https://...onrender.com`)를 친구들과 공유합니다.

무료 플랜은 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초쯤 걸립니다.
방 정보는 서버 메모리에만 있어서 서버가 잠들거나 다시 시작되면 진행 중인 방은 사라집니다.

## 플레이 방법

1. **캐릭터 관리**: 이름, 테마색, 도트 초상화(8종) 또는 이미지 URL, 성격, 특기, 한 줄 소개를 입력합니다.
   캐릭터는 내 브라우저에 저장되고, JSON 파일로 내보내거나 불러올 수 있습니다.
2. **친구와 플레이**
   - 방장: 참가 방식(내 캐릭터 / 진행자)과 에피소드를 고르고 **방 만들기**를 누릅니다. 4글자 초대 코드와 초대 링크가 나옵니다.
   - 친구: 초대 링크를 열거나 초대 코드를 입력하고, 데려갈 캐릭터를 골라 **참가하기**를 누릅니다.
   - 모두 모이면 방장이 **녹화 시작**을 누릅니다. 캐릭터는 최대 6명, 진행자는 1명까지입니다.
3. **탈출**: 화면은 3단입니다.
   - **왼쪽 (출연진)**: 같은 구역에 있는 멤버만 위치와 소지품이 보입니다. 내 아이템을 눌러 같은 구역 멤버에게 건넬 수 있습니다.
   - **가운데 (지도와 구역)**: 내 캐릭터가 가 본 곳만 지도에 드러납니다. 옆 구역을 눌러 이동하고, 아래에서 물건을 조사합니다.
   - **오른쪽 (채팅)**: 내 캐릭터에게 들리는 소리만 나옵니다.
4. **목소리가 닿는 거리**: 소리는 문이나 얇은 벽을 하나 건널 때마다 한 칸씩 멀어집니다.
   - 속삭임: 같은 구역에만 들립니다.
   - 대사: 같은 구역에 들리고, 바로 옆 구역에는 웅얼거리며 일부만 들립니다.
   - 외침: 옆 구역까지 또렷하게, 두 칸 떨어진 구역에는 웅얼거리며 들립니다.
   - 행동: 같은 구역에서만 보입니다.
5. **진행자(GM)**: 캐릭터 없이 모든 구역과 모든 대화를 지켜봅니다. 지도에서 구역을 골라 그 구역에만 나레이션을 넣거나,
   전체에 나레이션을 넣고, 시간을 멈추고, 시간 감소 없이 힌트를 줄 수 있습니다.
6. **성격과 특기**: 성격에 따라 자동 리액션 대사가 나오고, 특기는 퍼즐 풀이에 영향을 줍니다.
   - 관찰력: 조사할 때 추가 단서를 찾습니다.
   - 두뇌: 자물쇠 힌트를 무료로 봅니다.
   - 괴력: 일부 자물쇠를 힘으로 엽니다.
   - 행운: 틀려도 시간이 줄지 않습니다.
7. 오답을 내면 1분, 힌트를 보면 3분이 모두의 시간에서 줄어듭니다. 최종 탈출은 **전원이 한 곳에 모여야** 할 수 있습니다.
8. **엔딩**: 내 캐릭터 시점의 역극 로그를 `.txt`로 저장할 수 있습니다. 진행자는 전체 로그를 저장합니다.

창을 닫거나 새로고침해도 타이틀 화면의 **이어하기**로 같은 자리로 돌아올 수 있습니다.

## 공정한 플레이

판정은 모두 서버에서 합니다. 퍼즐 정답과 다른 구역의 대화는 브라우저로 아예 보내지 않으므로,
개발자 도구를 열어도 볼 수 없습니다. 웅얼거리는 소리도 서버에서 글자를 지운 뒤에 보냅니다.

## 에피소드 추가하기

`server/scenarios.js`의 `SCENARIOS` 배열에 같은 형식으로 에피소드를 추가하면 방 만들기 화면에 나타납니다.
지도 크기(`map`), 구역 위치(`rect`), 시작 구역(`starts`), 구역 사이 연결(`links`: 통로, 문, 소리만 통하는 벽)을
에피소드마다 다르게 정할 수 있습니다. 필드 설명은 파일 맨 위 주석에 있습니다.

## 도트 아이콘 추가하기

`public/js/pixels.js`의 `PIXEL_ICONS`에 12줄 × 12글자 격자를 추가하면 됩니다. 글자 하나가 픽셀 하나이고,
`.`은 투명, 나머지 글자는 `PIXEL_PALETTE`의 색입니다. 시나리오의 `icon` 값에 그 이름을 쓰면 됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `server/index.js` | 웹 서버와 실시간 통신(WebSocket) |
| `server/room.js` | 방, 게임 진행, 소리 전달, 판정 |
| `server/scenarios.js` | 에피소드(지도, 구역, 연결, 퍼즐, 힌트) — 정답이 있어서 브라우저로 보내지 않음 |
| `public/index.html` | 화면 구조 |
| `public/style.css` | 디자인 (음산한 빈티지 도트 테마) |
| `public/js/game.js` | 캐릭터 관리, 방 만들기·참가, 게임 화면 |
| `public/js/pixels.js` | 12×12 도트 아이콘과 캐릭터 초상화 |
| `public/js/voices.js` | 성격별 리액션 대사와 특기 정의 (서버와 함께 씀) |
| `public/fonts/` | Galmuri 픽셀 폰트 (SIL OFL 1.1, `public/fonts/OFL.md`) |
| `render.yaml` | Render 배포 설정 |
